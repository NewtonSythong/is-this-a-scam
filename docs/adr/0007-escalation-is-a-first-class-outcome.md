# Handing the Message to a Trusted Person is an outcome, not a fallback

No automated Check will be right every time, and the "we can't tell" Verdict needs a real next step rather than an apology. So every result offers one large button that sends the Message to a Trusted Person the Checker has chosen, with a pre-written "I got this message, is it real?" attached — and on a "we can't tell" Verdict that button is the primary action. This reframes the product from a classifier into an escalation tool with a classifier attached, which is both the more honest description and the more useful one. It is also the feature that makes the app worth setting up for a family member, and it cuts in both directions: it gives an older Checker a low-friction reason to contact someone, and a younger Trusted Person a concrete way to help.
