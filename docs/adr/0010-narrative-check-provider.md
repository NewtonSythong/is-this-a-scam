# The Narrative Check calls Claude directly with a schema the API enforces, and picks from a catalogue rather than writing prose

The earlier decision was OpenRouter, chosen because it was already familiar from Note-Pilot, needed one key, and allowed the model to be swapped without touching the Android app. That is reversed here. The Narrative Check's entire job is to return a fixed shape — a list of pattern identifiers, each with a quote from the Message — and the Anthropic SDK's structured outputs make that shape a guarantee the API enforces rather than a request the model may or may not honour. Behind a router, JSON reliability varies by whichever model is serving, which would put the burden of defensive parsing on the one component whose output is load-bearing for what a frightened person reads. The model is `claude-opus-5`, with adaptive thinking and effort set to medium: this is a short classification, but a wrong answer reaches someone frightened, so it does not get the cheapest setting either. Effort is the knob to turn once there is a real corpus to measure against, and it should be tuned on evidence rather than left where it was first put. The swap cost stays low regardless, because the Narrative Check is an interface — replacing the provider means writing one adapter, not touching the engine.

The deeper decision is what the model is allowed to say. It does not write the sentence a Checker reads. It selects from a catalogue of narrative patterns and quotes the words that made it select — and the Reason shown is the one written in that catalogue, in advance, by a person. Two guards then run before anything becomes a Signal: a pattern outside the catalogue is discarded, and a quote that does not appear in the Message is discarded with it, because a model that cannot point at the words it is describing is describing something that is not there. The quote itself never reaches the Checker; it exists solely so the claim can be checked, which turns hallucination into something the code detects rather than something the Checker has to notice. This is ADR 0003's rule that a Reason may only cite evidence an engine actually produced, made structural instead of aspirational. It costs nuance — the model cannot describe a scam shape the catalogue has not anticipated — and buys a guarantee about every sentence the app is capable of showing. For an audience who will believe what this app tells them, that trade is the right way round.
