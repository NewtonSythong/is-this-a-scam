# Stack: native Android (Kotlin/Compose, minSdk 26) over a Next.js/TypeScript API on Vercel, with no database

The Android app is native rather than a PWA because the chosen Entry Points — the text-selection menu and the quick-settings tile — are platform APIs with no web equivalent. `minSdk 26` (Android 8.0) is set deliberately high enough to clear all three Entry Points and low enough to cover the old handsets this audience actually carries. The API is Next.js and TypeScript on Vercel, matching Note-Pilot and PupPatrol, and it holds the keys the app must not ship: Safe Browsing, OpenRouter, and the curated Known Organisation list. A web page in the same Next.js app runs the identical engine so the project can be tried from a link, which a native-only build cannot offer. There is no database and therefore no Prisma and no Postgres, because ADR 0005 stores nothing. The Artifact Check is a plain, dependency-free TypeScript module the API imports, so it can be unit-tested with no network, no mocks and no framework.
